## 先有内容，再有页面

把文章放在 Markdown 文件中，页面只负责呈现。这样修改布局时，不必同时改动每篇文章。

## 内容集合

内容集合将文章字段统一起来：标题、日期、分类和标签都有明确的位置。

```typescript title="一份文章数据" mark="2"
const post = {
  title: '把页面交还给内容',
  tags: ['Astro', '博客'],
};
```

## 静态也可以交互

阅读进度、主题切换和本地搜索都可以在浏览器里完成。只有真正需要即时数据的功能，才需要额外服务。
